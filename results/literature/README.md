# Literature Artifacts

Machine-generated records of how sources were found and read. The PDFs
themselves live in `../../raw/sources/`; the summaries live in
`../../wiki/sources/`.

- `literature-search-2026-06-06/`: OpenAlex, Crossref, arXiv, and Semantic
  Scholar responses for 16 query clusters, the screening notes
  (`screened_candidates.md`), the download manifest, and extracted text for the
  35 PDFs downloaded in that batch.
- `ingest-2026-06-06-missing-aps/`: extracted text for the two APS papers that
  were added by hand after the search (Wang 2024, Lyu 2025).

These directories were moved here from `results/` on 2026-11-14. Paths written
inside the JSON manifests still use the old `results/literature-search-2026-06-06/`
prefix.

No search has been run since 2026-06-06. See
`../../wiki/project-status-review.md` for papers published since then that are
not yet in `raw/sources/`.
