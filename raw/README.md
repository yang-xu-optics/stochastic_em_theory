# Raw Sources

This is the immutable source layer for the project.

Put papers, notes, datasets, images, and external reference material here. Once
a source file is added, treat it as read-only. Derived notes and synthesis belong
in `../wiki/`, not here.

Recommended layout:

- `sources/`: PDFs, markdown clips, preprints, books, and technical notes.
- `assets/`: images, diagrams, and downloaded media referenced by sources.

Use stable filenames where possible, such as:

```text
YYYY-author-short-title.pdf
YYYY-author-short-title.md
```
