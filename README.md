# stochastic_em_theory

Research wiki, manuscript workspace, and simulation sandbox for stochastic
electromagnetic theory of squeezed-vacuum-driven high harmonic generation and
THz emission.

The directory is organized around the LLM Wiki pattern:

- `raw/`: immutable source material.
- `wiki/`: Codex-maintained research synthesis with `index.md` and `log.md`.
- `AGENTS.md`: Codex operating schema for maintaining the wiki and simulations.
- `code/`: numerical simulation implementation workspace.
- `results/`: generated outputs, figures, and run manifests.
- `paper/`: manuscript outline and drafts.

Start by reading `AGENTS.md`, then `wiki/index.md`.
